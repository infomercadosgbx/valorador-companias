What you get with UiPath Maestro Orchestrate

The engine behind shorter cycle times and compliance you can prove. BPMN, Case, and Flow all run on it, so each team models the process its own way and every instance gets the same control, history, and governance.

No cap on duration or concurrency

An instance holds state for hours, days, or weeks while it waits on a person, a system, or an event. A human step waits as long as the process needs.

Full control of a live instance

Retry, cancel, pause, resume, migrate, or go-to on any running instance, one at a time or in bulk. Correct a running process without redoing completed work.

Complete process history

Every step and variable, durations, completion rates, and service-level agreement (SLA) compliance, with dashboards, alerts, and the Maestro API.

Trust built in from the first run

Evaluations prove a process before it goes live, and guardrails cover any agent step. Access control, publishing approvals, and model governance come from the UiPath Platform.

Maestro Orchestrate: common questions

How Maestro Orchestrate works with the rest of your UiPath investment, what it needs to run, and what it costs.

Request demo

Which canvas should I use: Maestro BPMN, Maestro Case, or Maestro Flow?

The engine is the same, so the choice comes down to how your team works. Maestro BPMN suits a process that must be modeled to a standard business and IT both sign off on. Maestro Case suits work where no two cases follow the same path. Maestro Flow suits a team building inline with a coding agent.

Will Maestro Orchestrate work with the automations and integrations I already have?

Yes. Every workflow, integration, and credential already in your UiPath tenant is callable as a node, and each of those runtimes can call a process in return. Nothing to migrate. Out-of-the-box connectors cover ERP, HRIS, CRM, and ITSM systems.

What do I need to run Maestro Orchestrate?

An Automation Cloud tenant or Automation Suite 26.10. Orchestrator, Actions, Integration Service, Data Fabric, Document Understanding or IXP, and Insights need to be enabled for every step type and for monitoring to work. Authoring happens in VS Code, Studio Web, or Studio Desktop.

Are there limits on how long a process can run or how many can run at once?

No. Maestro Orchestrate has no cap on execution duration or concurrency, and a human step waits as long as the process needs. Short-running workflows of agents and APIs are a separate product, Maestro Automate, where an instance finishes inside 24 hours.

Does Maestro Orchestrate support BPMN 2.0 and DMN?

Yes. Maestro BPMN models follow BPMN 2.0 notation, extended with UiPath tasks for robots, agents, and sub-processes. Decision logic is authored in Decision Model and Notation (DMN) decision tables, versioned alongside the model.

How are Maestro Orchestrate processes governed and audited?

Governance policy, model governance, role-based access control, maker-checker publishing approvals, and release governance apply from the first run. Guardrails are available on any agent step. Every instance keeps a tamper-evident audit log for the life of the process.

How is UiPath Maestro Orchestrate priced?

Maestro Orchestrate is included with the UiPath Platform. See plans and pricing for details.

How do I get started?

Create a project under Business Orchestration in VS Code, Studio Web, or Studio Desktop, and pick Maestro BPMN, Maestro Case, or Maestro Flow. There is nothing to install: Maestro Orchestrate is available on the tenant by default.
